# LinkedIn, Decoded

A single-file interactive dashboard built from my LinkedIn data export — 20 years of professional life across 40+ CSV files, visualized.

**Live:** https://joshuaharbo.github.io/LinkedIn-Decoder/

Eleven sections: network universe, LinkedIn's ad-targeting inferences vs reality, unanswered DM analysis, posting-vs-growth correlation, company follows, inbound/outbound invitations, connections vs real relationships, connection timeline, inbox quality, career layers, and a content-strategy deep dive.

Built with Claude (Cowork), Chart.js, and D3. Inspired by [Logan Currie's LinkedIn Data Export Visualization](https://loganhc-09.github.io/LinkedIn-Data-Export-Visualization/). Names of other people are anonymized; analysis runs entirely client-side.
